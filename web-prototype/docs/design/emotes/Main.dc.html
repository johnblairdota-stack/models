Prime Time · the face

A new 2D face, traced off the robot we actually built

The old lobby face was a stand-in — a diamond on a blob, drawn before the character existed. This one is measured: the silhouette comes off the front render, and the eyes, brow arcs and mouth come off the shader that paints the real faceplate, at the same proportions it uses.

THE BUILT ROBOT
THE NEW DRAWING
Helmet + pods Rounded shell, side pods, a lighter crown cap. Takes the player's shell colour.
Faceplate Dark blue glass. Stays blue for everyone — it is the robot, not the player.
The light Eyes, brow arcs and mouth are emissive. This is where the player's accent colour goes.
Why it matters The face is a screen, so an emote is just the light redrawn. No new art, no second pipeline.
