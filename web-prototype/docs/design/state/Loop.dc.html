Who decides what

  • The guide picks the chair and speaksone spoken word per expedition — the only frame difference on any phone all game is the guide hearing it echoed back
  • The runner drives the robotthrottle and bearing from the phone; the drivable-frame contract keys off throttle alone because the wire has no idle
  • Everyone else watches the televisionand, at Debrief, argues from a board they can all read equally
  • The server owns the clock, the deal and the truththe television is a client; its report is accepted only during EXPEDITION and only the fields named

What the wire lets through

  • Deny by default, field by fieldone declarative table in net/party/entitle.js; the server projects from it and a gate checks the observed wire against it
  • The table is shared, the projection is notor a bug in the filter would pass its own gate
  • A claim is published, and publishing is one-wayrowed all — the dead may not publish one
  • A vote may change until the phase closesand is not aired until then
  • log.reunion() is log.all()the reunion withholds nothing; everything the show ever knew comes out

Where the loop still leaks

  • 71.3% of games execute after the result is lockedfoldWin fires on the winning camera; closeEpisode() waits for the phase queue to empty
  • The vote is worth +2.1 points over guessingn = 14,064, and it does not improve across episodes
  • The Debrief argues about six shared facts116 of 126 log entries a game are public; nobody holds anything anyone wants
