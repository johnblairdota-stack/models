THE GHOST
Never a blank screen. A last-known mark that inflates as it ages, so the question stops being “do I know” and becomes “is this still true”.
The lever
Judging when a ghost is too old to act on. Plus one real choice: with more than one camera lit, only one is on air at full refresh — so the guide can park their attention on the room ahead and be deliberately blind behind.
How an honest guide is wrong
Staleness, and the arithmetic is damning about the shipped default. At stage 1 the Hunter crosses an 8 m room in 3.90 s, while ghost()'s halfLife = 6 reports 0.50 confidence on information already worthless. Set halfLife = roomSpan / HUNTER_SPEED[stage] — 3.90 / 2.96 / 2.39 s — and the error rate rises with the Hunter's stage, which is a difficulty curve for free.
How the table argues
“It was eight seconds old” is a defence with a number in it, which beats “I had nothing”. The room has a partial check, because the TV shows the Hunter whenever a camera catches it, so everyone knows roughly when the last public sighting was — but they never see the guide's clock.
What it costs
The cheapest by a distance. darkrun.js ghost() is already written, already asserted by dark-run D6/D6b, and deliberately unwired. sightForGuide()'s return shape barely changes — add an age.
Where it breaks
It is still one channel, and still fundamentally “how stale is this”. A good guide learns one threshold — about four seconds — and applies it mechanically from then on, so the skill is thin and exhausted inside a game or two. A fading blob is also genuinely hard to draw legibly at 390 px.
