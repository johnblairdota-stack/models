THE DESK

Prime Time production office · intake board
PITCH → ROUTE → VERIFY → ✓ DONE

Chat is not intake.

Right now a feature ships when a chat scrolls past. No sell, no route, no gate — five agents' playtest findings died in transcripts in August because nothing made them land anywhere. The Desk is one board: a card is pitched, routed to an owner (Spec · Game · Art · Critic · Skills), and verified by the backend against the real repo.

Done is not a lane. There is no Done button. Done is a backend check that passed — a grep of the spec, a live import of the wire, a spawned harness that exits 0. Re-verify a Done card whose check now fails and it falls back to Verify.

PITCHanyone can pitch — hunches welcome, labelled

ROUTEspec · game · art · critic · skills — a name goes on it

VERIFYthe backend reads the repo, not the board

✓ DONEcontinuously earned, never granted
